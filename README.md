# نظام إدارة النتائج المدرسية

نسخة محلية أولية من نظام إدارة وتحليل النتائج المدرسية، مبنية باستخدام React + TypeScript + Vite، مع دعم RTL وتخزين محلي عبر IndexedDB.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية، وغالبًا:

```text
http://localhost:5173
```

## البناء للإنتاج

```bash
npm run build
```
