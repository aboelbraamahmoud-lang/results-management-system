# نظام إدارة وتحليل النتائج المدرسية — النسخة المحلية 0.1

هذه حزمة تأسيسية للنسخة المحلية الأولى، ومصممة بحيث تتحول لاحقًا إلى نسخة Supabase دون إعادة بناء الواجهة. تحتوي حاليًا على:

- لوحة معلومات فعلية مبنية على البيانات المحلية.
- محرك حساب مركزي للنسب والنجاح والمستويات.
- دعم درجات كلية مختلفة لكل سجل/اختبار.
- تخزين النتائج والإعدادات في IndexedDB.
- استيراد Excel / CSV مع اختيار Sheet ومطابقة الأعمدة وفحص البيانات.
- إعداد اسم المدرسة والعام والفصل وحد النجاح وحدود مستويات الأداء.
- عرض النتائج والبحث فيها.
- تقرير أولي «ملخص النتائج» قابل للطباعة.
- بيانات تجريبية يمكن تحميلها ومسحها.

## التشغيل

1. ثبّت Node.js إصدار حديث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:

```bash
npm install
npm run dev
```

سيظهر عنوان محلي مثل:

http://localhost:5173

## بناء نسخة الإنتاج

```bash
npm run build
```

النسخة الناتجة ستكون داخل مجلد `dist`.

## المرحلة التالية

سيتم توسيع نفس المشروع ليشمل تحليل المدرسة والأقسام والمواد والمعلمين والصفوف والشعب والطلاب، المقارنات بين الاختبارات، تحليل المستويات، الراسبين، سجل الاستيراد وUndo Import، التقارير الكاملة، PDF/Excel/CSV، النسخ الاحتياطي، ثم نقل Data Service لاحقًا إلى Supabase.
